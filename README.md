# ozon-images

Ozon 商品图测试托管仓库（GitHub Pages）。文件按 `<产品>-<图位>.jpg` 命名，直接放在仓库根目录。

## 当前内容

`makeup-bag-*.jpg`：3 张**测试用**化妆包图（AI 生成，仅验证「本地图 → 公网直链 → Ozon 抓取」链路，不作为真实上架素材）。

- makeup-bag-01-main.jpg：白底主图，1200×1600（3:4）
- makeup-bag-02-detail.jpg：拉链与内衬细节
- makeup-bag-03-scene.jpg：梳妆台场景

## 访问方式

启用 Pages 后，直链形如：

```
https://<用户名>.github.io/ozon-images/makeup-bag-01-main.jpg
```

## 注意

- 公开仓库，任何人可访问这些图片；不要放含个人信息、未授权品牌 logo 或未上架新品的高价值素材。
- 仓库软上限约 1GB，单文件 100MB。只适合测试和小批量；放量换对象存储（R2/OSS）。
